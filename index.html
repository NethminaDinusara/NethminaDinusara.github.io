Build log

three builds

Multi-Task Robotic Vehicle

COMPLETE

A modular robotic vehicle on ESP32 that pulls several sensors and motor drivers into one system instead of one board per job. The interesting part is the software: I'm structuring the firmware so a new sensor or behaviour can be added without rewriting the control loop.

Ongoing work is debugging and performance tuning — timing, sensor noise, and keeping the loop responsive as modules stack up.

  • ESP32
  • Embedded C
  • Arduino IDE
  • Motor drivers
  • Multi-sensor

Pet Robot

IN PROGRESS Individual Design Project — Semester 4

Designed and built a pet robot as my Individual Design Project at KDU — mechanical design, electronics and behaviour, end to end. This is the work I care most about: robots that read their surroundings and respond in a way a person can actually read back, rather than just execute a path.

It's also what pointed me toward humanoid robotics as the direction I want to take further.

  • Arduino
  • Embedded C
  • Sensor integration
  • SolidWorks

Autonomous Line-Following Robot

COMPLETE

An autonomous line follower on Arduino using IR sensors for path detection, with motor-control logic I wrote rather than lifted, tuned for accurate cornering at speed.

I owned the whole build cycle — hardware integration, debugging, testing and optimization — which is where I learned how much of robotics is measurement, not code.

  • Arduino
  • Embedded C
  • IR sensors
  • DC motors
